# Waflo Mobile M1 handoff

This directory is the portable evidence bundle for the Flutter M1 staff-device foundation. It contains summaries, screenshots generated by Flutter golden tests, raw safe test output, a checksum manifest, and a portable source archive.

No production credentials, usable pairing QR, private key, signing material, backend runtime source/data, or customer/staff data is included. Contract fixtures are explicitly non-credential and server-invalid.

Start with `FINAL-COMPLIANCE-MATRIX.md`, `TEST-SUMMARY.md`, and `SCREENSHOT-MANIFEST.md`. External iOS/GitHub Actions results remain pending until a pushed workflow run exists.
