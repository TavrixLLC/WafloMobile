# Arabic and RTL

Arabic remains generated from ARB resources with no hardcoded visible M3B
copy. Home, scanner, loyalty, quantity controls, reward-ready, redeem,
confirmation, errors, blocked states, security, and App Lock preserve true RTL.

Arabic operation wording was refined from issuance language to natural “إضافة
الطوابع”. Directional spacing and navigation icons use directional APIs.
Authoritative merchant/location names and ISO currency codes are not translated;
LTR numeric progress and mixed Latin values remain isolated and readable.
