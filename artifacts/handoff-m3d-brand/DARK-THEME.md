# Dark theme

The brand package supplies light tokens and dark logo variants but does not declare a complete application dark palette. M3D derives these values conservatively and labels them as derived, not official source tokens:

| Role | Derived value |
|---|---|
| Canvas | `#17100F` |
| Surface | Warm Ink `#241916` |
| Elevated surface | `#322522` |
| Outline | `#5A4742` |
| Primary action | Flow Coral `#FF6B4A` with Warm Ink text |
| Primary text | `#FFF4F1` |
| Supporting text | `#C8B8B3` |
| Scanner overlay | Warm Ink at 85% opacity |

The dark theme is not a blind inversion. Brick/Coral remain recognizable, semantic statuses stay distinct, official white logo assets are used on dark trust surfaces, and merchant-owned stamp artwork is not recolored.

Dark Home, scanner, customer, manager approval, App Lock, and status states are included in the executable review evidence.
