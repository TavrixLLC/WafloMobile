# Iconography

## Brand assets

Official Waflo mark and horizontal lockup are used only for startup, pairing introduction, App Lock, and fail-safe/trust states. They are not treated as universal action icons and are not redrawn, recolored, stretched, shadowed, stroked, or rotated.

If an asset cannot load, the component falls back to the separate Waflo flow-dot status motif rather than approximating the official mark.

## System actions

Back/close, flashlight, camera, settings, language, theme, and device-security controls remain recognizable Material system actions with semantic labels and minimum touch targets.

## Semantic status

Success, warning, danger, offline, and security states retain distinct semantic iconography. Brand Brick is not reused as the destructive color merely because it is red-adjacent.
