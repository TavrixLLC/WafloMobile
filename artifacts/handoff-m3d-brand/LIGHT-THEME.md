# Light theme

The light theme follows official source authority directly:

- Canvas: Cloud `#F7F9FF`
- Surface: White `#FFFFFF`
- Primary text: Warm Ink `#241916`
- Supporting text: Muted `#76645F`
- Primary action: Waflo Brick `#AE3115`
- Pressed/deep action: Ember `#7D2311`
- Controlled accent: Flow Coral `#FF6B4A`
- Support highlight: Soft Coral `#FFF0EC`
- Semantic success/warning/danger: official values

White body text is used on Brick, not directly on Coral. Coral surfaces use Warm Ink where text is required. Cards use the official 22px radius and only high-value groupings receive the 12/32 Warm Ink shadow concept.

Home keeps one visually dominant Brick scan action. Operational screens use whitespace and typography before adding another surface.
