# App Store Review notes

1. Open Waflo Staff and leave **Pair this device** as the normal merchant route.
2. Select **Review / Demo Access** below the normal action.
3. Enter `<REVIEW_ACCESS_CODE_FROM_SECURE_RELEASE_CONFIG>` supplied in App Review Information.
4. Continue through secure device challenge establishment to Home. A restrained **Demo mode** indicator confirms fictional data.
5. Open Review Tools from Settings to select New, Active 5/8, Reward Ready 8/8, Manager Approval Required, threshold, billing, or invalid-code scenarios.
6. Use the submission QR images supplied out-of-band after environment provisioning. Test scan, stamp, reward-ready, redemption-required/pending, reset, Arabic, dark mode, App Lock, and Exit Demo.

Manager approval is intentionally external server authority; the Staff app does not contain an Approve control. Exit Demo revokes/clears the review session and returns to normal pairing. The credential and QR images are never stored in this Git handoff.
