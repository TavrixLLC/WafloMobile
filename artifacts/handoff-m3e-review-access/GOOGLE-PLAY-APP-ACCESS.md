# Google Play App Access

Use **Review / Demo Access** beneath normal device pairing. The release operator supplies `<REVIEW_ACCESS_CODE_FROM_SECURE_RELEASE_CONFIG>` only in Play Console App access credentials. After entry, the app establishes an Ed25519-bound review Device session and displays **Demo mode**.

Review Tools provides seven fixed fictional scenarios and reset. Submission QR images are generated from the deployed review tenant and supplied through the secure review instructions. No real merchant/customer data, billing, wallet issuance, communication, or provider credentials are involved. Exit Demo clears review authority and returns to normal pairing.
