# App Store Review Notes

Waflo Staff normally uses merchant-authorized device pairing. App Review receives access only to an isolated review environment containing fictional sample data.

1. Launch Waflo Staff.
2. Open the customer/pairing scanner from the normal setup flow.
3. Select **Enter code instead**.
4. Enter `<REVIEW_ACCESS_CODE_FROM_SECURE_RELEASE_CONFIG>` supplied securely in App Review Notes.
5. Continue into the isolated Waflo review environment.

The credential is validated by the server and cannot access real merchant tenants. A small Demo indicator appears only after authorization. Use Review Tools to select/reset fixed sample scenarios, then inspect scanner, 0/8, 5/8, 8/8 reward-ready, stamp, reward, manager-approval presentation, App Lock, Arabic, dark mode, and exit.
