# Hidden Demo entry

Removed from Pairing: visible Demo/Review prompt, visible access button, local Demo introduction, and dedicated pre-auth Review screen.

Current owner/reviewer route:

1. Open the normal pairing scanner.
2. Select **Enter code instead**.
3. Enter the code supplied through the appropriate secure operational channel.
4. Only after authorization does a Demo indicator appear.

An invalid ordinary value follows safe generic pairing/code failure and does not reveal the local Demo feature. No Demo clue appears on Pairing, Home, or Settings before authorization.
