# Waflo Staff Mobile design pack

This is a sanitized visual and UX reference for browser-based design exploration. It is not a production source archive and contains no usable authentication material, customer data, network client, or backend implementation.

The current product is a focused retail Staff utility: pair, scan, resolve, stamp or redeem, confirm success, then scan the next customer. Screenshots use deterministic fictional fixtures. Current UI is engineering-approved, not product-owner visual approval.

Start with `16_LOVABLE_INSTRUCTIONS.md`. Preserve the product and security boundaries in every concept.
