# Staff flow map

```text
Pair device
  → Home
  → Scan customer
  → Resolve customer
  → Customer loyalty
      → Add stamps → Confirm → Success
      → Redeem → Confirm → Manager approval when required → Success
  → Scan next customer
```

Supporting states: startup, App Lock, Device & Security, Settings, offline, update required, session expired, device revoked/compromised, location authority loss, billing blocked, purchase threshold failure, and ambiguous transaction recovery.

The scanner's manual-code affordance is generic. Demo/Review identity is shown only after successful authorization.
