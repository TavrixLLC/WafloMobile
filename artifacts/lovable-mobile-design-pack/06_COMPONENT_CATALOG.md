# Component catalog

- Brand mark: reserved for startup, pairing, App Lock, and deliberate system moments.
- Primary action: Brick fill, white label, Ember pressed state.
- Secondary action: neutral or outlined; must not compete with the transaction CTA.
- Status pill: quiet live state, readable over scanner content.
- Scanner frame: adaptive square, Coral corners, dim outside region, restrained beam.
- Customer identity header: name first, program second.
- Loyalty progress: exact filled/empty slots with semantic progress label.
- Reward region: outside the grid; celebratory but operational.
- Confirmation summary: customer, action, relevant amount, clear cancel.
- Success state: authoritative result plus Scan Next Customer.
- Error/recovery: severity-specific copy/action; not one generic red page.
- Demo indicator: small and persistent only after authorized Demo/Review entry.
