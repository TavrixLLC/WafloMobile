# State catalog

Scanner: initializing, requesting permission, permission denied, permanently denied, ready/scanning, QR detected, resolving, resolved, invalid, expired, offline, resolve failed, camera unavailable, backgrounded.

Operations: idle, customer resolved, stamp input, stamp confirmation, stamp success, reward ready, redeem confirmation, approval required/pending/rejected/expired/invalid/stale, checking command status, redemption success, safe failure.

Device: unpaired, ready, pending, revoked, compromised, session expired, update required, network unavailable, App Locked, fatal configuration error.

Never collapse distinct camera detection and customer resolution into one fake success state.
