# Scanner UX

Camera first. Normal, server Review, and local Demo use one presentation system.

- Adaptive square target; strong, restrained Waflo corners.
- Dim only outside the target.
- A low-opacity beam travels vertically on a 2.3-second cycle only while scanning.
- Stop the beam immediately on detection.
- Show “QR detected” before “Loading customer…” so optical and network authority are distinct.
- Torch reflects hardware state.
- Reduce Motion uses a static target.
- Pause in the background and during resolution; single-flight prevents duplicate handling.
- Demo simulation controls are an authorized-only bottom sheet, never permanent camera chrome.

Reject neon, particles, excessive glow, sci-fi decoration, fake camera activity, and slow transitions.
