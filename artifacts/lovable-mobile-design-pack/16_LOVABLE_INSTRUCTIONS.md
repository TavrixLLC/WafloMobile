# Instructions for Lovable

This package is a visual/UX authority pack. Analyze the current Waflo Staff interface, identify hierarchy and usability weaknesses, and create browser-based interactive mobile prototypes using the supplied states, assets, localization, and invariants.

Do not implement production authentication, recreate a backend, invent business logic/security architecture/customer data, or change loyalty semantics. Do not treat browser prototype code as production Flutter code.

## First design round

Redesign only Home, Scanner, Customer Loyalty, Stamp/Reward, Success, and App Lock. Provide three genuinely distinct directions:

- A — Warm Operational: quiet surfaces, friendly clarity, very fast retail hierarchy.
- B — Premium Waflo: editorial type, refined spacing, confident brand moments, restrained depth.
- C — Bold Utility: stronger contrast and larger task controls without dashboard clutter.

For each direction, show English light plus representative Arabic RTL, dark, and large-text states. Preserve all state and security constraints. Stop after this round for owner direction selection before expanding the full screen set.
