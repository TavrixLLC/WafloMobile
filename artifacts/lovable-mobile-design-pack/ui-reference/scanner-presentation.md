# Scanner presentation structure

```text
Camera preview
  + dim-outside-target overlay
  + adaptive rounded-square target
  + four brand corner brackets
  + conditional 2.3-second beam
  + safe-area top row (close, title, location when available)
  + bottom instruction
  + live status pill
  + capability controls (torch; authorized Demo sheet only after entry)
```

Input adapters own camera and fixture behavior. Presentation owns no authorization decision.
