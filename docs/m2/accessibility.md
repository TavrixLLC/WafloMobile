# Accessibility

M2 uses localized labels for scanner instructions, flash, cancel, Membership summary, amount selector, purchase fields, reviews, confirmation, success, rewards, final reset, pending recovery, and errors. Interactive controls use standard Material touch targets and expose meaningful disabled states.

The stamp grid provides one concise semantic progress summary and suppresses per-slot noise. Arabic uses RTL layout while the stamp chronology stays LTR. Widget and emulator coverage includes Arabic, 200% text, dark theme, concise semantics, and layouts that scroll instead of clipping. No business animation is required; therefore reduced-motion preference cannot be violated.
