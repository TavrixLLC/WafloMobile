# Rewards

Available rewards appear outside the stamp grid with contract name, description, milestone/final label, threshold, expiration, count/maximum, instructions, and approval requirement. Only `AVAILABLE` and unexpired rewards with remaining redemption count are actionable.

Location redemption capability controls all actions. A Manager-required reward enters an explanatory unavailable state; M2 neither asks for a PIN nor creates or bypasses an approval flow. Expired, voided, redeemed, or unknown reward states never become redeemable.
