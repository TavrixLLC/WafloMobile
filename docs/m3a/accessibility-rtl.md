# Accessibility, Arabic, and appearance

English and Arabic are generated from ARB resources; no new Staff-facing copy
is hardcoded. Arabic uses true RTL direction, mirrored navigation affordances,
logical alignment, and tested mixed Arabic/Latin currency content.

Primary controls meet a 48 dp minimum target. Scanner flash/cancel, Home Scan,
operation confirmation, recovery, App Lock, and Device & Security actions have
concise semantics. The stamp grid announces one grouped phrase such as “5 of 8
stamps” rather than eight individual positions; visible state is still only
FILLED or EMPTY and never relies on color alone.

The shared semantic-token theme covers light and dark appearance. Layouts use
wrapping and scrolling for large text. Executable screenshots cover Arabic,
dark mode, and 200% Home/customer layouts.
